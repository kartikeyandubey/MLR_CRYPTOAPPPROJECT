# Vertex Exchange

Convert your crypto into USDT and INR, without the hassle.
Vertex Exchange is a platform-independent crypto exchange application that makes converting cryptocurrency into USDT or Indian Rupees (INR) simple and straightforward.
Note: This is an academic project, not a licensed or regulated exchange. Cryptocurrency values can change quickly and carry risk. Nothing here is financial advice.

## About

- Fifth-semester live project by B.Tech Computer Science students at SRM University Delhi-NCR, Sonipat, Haryana
- Built to remove the confusion and extra steps involved in converting crypto
- Gives users one focused place to go from choosing a cryptocurrency to completing a conversion

## Features

- Convert crypto to USDT
- Convert crypto to INR
- Platform independent
- Review conversion details before confirming
- Transaction records stored in the database
- Separate frontend, backend and database

## How It Works

- Choose the cryptocurrency and enter the amount
- Pick the target: USDT or INR
- Review the conversion details
- Confirm to complete the conversion

## Architecture

- Frontend: the interface users interact with, plus input validation
- Backend: conversion logic and transaction processing
- Database: stores transactions and application data
